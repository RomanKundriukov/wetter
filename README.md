# Wetter – Standortbasierte Wetter-App (WinUI 3)

Eine moderne Windows-Wetter-App als Schulprojekt: **Wetterübersicht basierend auf der aktuellen Position** mit **aktuellem Wetter**, **Stundenübersicht** sowie **Vorhersage für mehrere Tage** inklusive **grafischer Darstellung** (z. B. UV-Index, Regen, Schnee).

> Repository: https://github.com/RomanKundriukov/wetter

---

## ✨ Funktionen

- **Standortbasiert**: Wetterdaten automatisch nach aktueller Position
- **Aktuelles Wetter**: z. B. Temperatur, Luftfeuchte, Windgeschwindigkeit, Windrichtung
- **Stundenübersicht**: kompakte Kacheln/Timeline pro Stunde
- **Tagesvorhersage**: Min-/Max-Werte für **3 Tage** und **7 Tage**
- **Diagramme**: grafische Darstellung pro Stunde (z. B. UV-Index / Regen / Schnee)
- **Modernes UI**: Dashboard mit Cards/Blöcken (ScrollViewer + Grid)
